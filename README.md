# Experiment 5: Simple Linear Regression

## Overview
Fits an Ordinary Least Squares (OLS) Linear Regression model to predict sales from advertising spend, calculating slope, intercept, Mean Squared Error (MSE), and R² score.

- **Libraries Used**: `numpy, matplotlib, scikit-learn`
- **Key Concepts**: `Linear Regression, Least Squares, MSE, R2 Score, Best Fit Line`
