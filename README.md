# Experiment 6: Logistic Regression Classification

## Overview
Trains a multiclass Logistic Regression classifier on the Iris dataset, evaluating accuracy, precision, recall, F1-score, and displaying a confusion matrix heatmap.

- **Libraries Used**: `scikit-learn, matplotlib, seaborn`
- **Key Concepts**: `Binary/Multiclass Classification, Confusion Matrix, Precision, Recall, F1`
