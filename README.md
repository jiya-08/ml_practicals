# Experiment 3: Principal Component Analysis (PCA)

## Overview
Performs dimensionality reduction on the 4-dimensional Iris dataset using PCA, transforming features into 2 principal components with scatter plot visualization.

- **Libraries Used**: `pandas, matplotlib, scikit-learn`
- **Key Concepts**: `Dimensionality Reduction, Feature Scaling, Eigenvectors, PCA Projection`
