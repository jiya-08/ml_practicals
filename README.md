# Experiment 9: Neural Network (Multi-Layer Perceptron) Classification

## Overview
Builds a Multi-Layer Perceptron (MLP) neural network classifier to learn nonlinear decision boundaries on the Iris dataset and evaluates classification accuracy.

- **Libraries Used**: `numpy, scikit-learn`
- **Key Concepts**: `Artificial Neural Networks, MLPClassifier, Backpropagation, Hidden Layers`
