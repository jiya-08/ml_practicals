# Experiment 8: Decision Tree Classification

## Overview
Builds and evaluates Decision Tree classifiers on the Iris dataset using Gini and Entropy impurity criteria, outputting confusion matrix and classification metrics.

- **Libraries Used**: `scikit-learn, matplotlib`
- **Key Concepts**: `Decision Trees, Gini Impurity, Information Gain, Tree Pruning`
