# Experiment 11: K-Means Clustering

## Overview
Implements unsupervised K-Means clustering algorithm on the Iris dataset, comparing clustering performance across cluster counts (K=2 to 6) using Euclidean and Manhattan distances.

- **Libraries Used**: `numpy, collections, scikit-learn`
- **Key Concepts**: `Unsupervised Learning, K-Means Clustering, Centroid Update, Distance Measures`
