# Experiment 10: Within-Class, Between-Class and Total Scatter Matrices

## Overview
Computes Within-Class Scatter (SW), Between-Class Scatter (SB), and Total Scatter (ST) matrices on the Iris dataset, mathematically verifying the identity ST = SW + SB.

- **Libraries Used**: `numpy, scikit-learn`
- **Key Concepts**: `Scatter Matrices, Linear Discriminant Analysis (LDA), Multiclass Separability`
